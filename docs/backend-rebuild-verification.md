后续配置审查注意事项（尚未修改线上）：

- 上线前需要连同 include 中的 `location` 检查代理头，不能只看 `server`：子级存在 `proxy_set_header` 时不会继承父级整组设置，见 [Nginx 代理头继承说明](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_set_header)。还需核实超时、上传大小；面板缓存开关已确认关闭。此项留待授权操作时核对，不再要求用户重复收集目标地址。
- Origin 为空会被当前规则放行，所以该规则不等于身份认证或管理员访问控制。正则只允许主域名及单层子域名，与注释中的“所有子域名”不完全一致；保留已使用的 `local.sitkin.top` 开发入口。暂不擅自放宽或更换规则。
- 配置中列出了 TLS 1.0 / 1.1；正式新入口按客户端要求核对后收敛到 TLS 1.2 / 1.3，参考 [Nginx TLS 协议说明](https://nginx.org/en/docs/http/ngx_http_ssl_module.html#ssl_protocols)。不能只凭这段文本断言线上实际接受哪些协议。
- PocketBase 的可信代理头设置需结合网络隔离和转发链确认，不能信任来自任意客户端的头；参考 [PocketBase 反向代理说明](https://pocketbase.io/docs/going-to-production/#using-reverse-proxy)。
- 聊天中的 Markdown 代码围栏与转义符不作为可直接部署的 Nginx 配置保存。
