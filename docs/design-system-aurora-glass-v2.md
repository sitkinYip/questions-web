# 赴星之约（Starward）极光玻璃 v2 设计与样式规范

> 生效时间：2026-11  
> 适用范围：`questions-web` 全部正式业务界面、本地交互预览页（`preview-v2.html`）以及后续向鸿蒙原生端（`starward_hm`）迁移时的视觉与交互基线。  
> 单一令牌源码：[src/styles/foundation/tokens.css](../src/styles/foundation/tokens.css)、[src/design/tokens.ts](../src/design/tokens.ts)。

## 1. 设计原则与反模板红线

1. **按结构重构，绝不只换色**：每次视觉改造必须核对真实页面的信息层级、容器形态、控件排版、交互状态与留白比例，禁止在旧 DOM 骨架上仅替换主题变量敷衍了事。
2. **双端独立适配**：桌面端（`>= 1100px`，唯一边界 `useDesktopLayout`）必须使用专属分栏、双列或工作区布局，严禁把移动端单列布局简单拉宽。
3. **双入口全覆盖**：同一业务若有多个呈现入口（例如「来信」同时存在 `/notifications` 独立路由页和答题内的 `NotificationDialog` / 悬浮铃铛），必须同步改造，不得遗漏。
4. **克制文案、清除 AI 味**：
   - 严禁保留装饰性英文 eyebrow（如 `CHAPTER`、`QUEST SESSION`、`UNLOCKED ARCHIVE`、`IMPORTANT SIGNAL`、`RANK`、`Decoded fragment`、`Combined revelation`）。
   - 严禁堆砌空洞口号、重复副标题、引导废话（如「点击查看已解锁内容」「Archive verified」）和「卡片套卡片套卡片」的多层嵌套边框。
   - **保留真实业务事实**：等级限制、开放/截止时间、核销指引、密码要求、未读提醒、失败原因与重试动作必须清晰可见，不能隐藏进隐喻。
5. **原生迁移友好（Web → HarmonyOS ArkUI）**：避免 `mask-image`、`clip-path`、多重叠加 CSS 滤镜和难以原生映射的奇异几何；所有色板、圆角、材质层级和缓动曲线均对应 ArkUI 能力边界。

## 3. 三层玻璃材质与沉浸光感

| 层级              | 适用对象                                                                                            | 材质实现                                                                                                                                                      | `backdrop-filter`                            | 降级策略                                                                                                        |
| ----------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **L0 环境底景**   | 全局页面背景（`base.css`）                                                                          | 固定视口深空/雾白径向微光 + 稀疏星点，不随滚动重绘                                                                                                            | 无                                           | 静态纯底色                                                                                                      |
| **L1 内容玻璃卡** | 场次卡、题卡、收藏卡、来信行、护照卡、桌面线索手记                                                  | `--color-glass-card` 纵向微渐变 + `1px` 细边（`--color-border-strong`）+ 顶部 `1px` 内高光（`inset 0 1px 0 var(--color-glass-highlight)`）+ 指针/触控径向柔光 | **禁止使用**（避免长列表滚动掉帧与玻璃失真） | 保持实体微透表面                                                                                                |
| **L2 悬浮控制层** | 移动悬浮底栏、桌面悬浮顶栏、答题顶栏胶囊、Sheet、Dialog、账号气泡、浮动线索胶囊、`StarBurstOverlay` | `--color-glass-floating` / `--color-burst-backdrop` + 受控两档模糊（柔 `20–24px` / 强 `28–40px`）+ 顶部内高光                                                 | 允许（仅 L2）                                | `@media (prefers-reduced-transparency: reduce)` 或 `@supports not (backdrop-filter)` 时回退为实体表面并关闭模糊 |

**光感交互边界**：

- 移动端悬浮胶囊底栏的**触摸跟随流光与拖动切页交互**必须完整保留（见 `e2e/mobile-layout.spec.ts`）。
- 题卡与内容卡只通过柔光斑和描边亮度响应指针/触控，玻璃本身不发生 3D 畸变或过度缩放。

## 4. 字体、数字与 4 档圆角体系

### 4.1 字体与排版

- **零外链字体**：统一采用系统原生无衬线字体栈 `"HarmonyOS Sans SC", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, -apple-system, sans-serif`。
- **等宽数字**：所有题号、等级（`Lv.x`）、进度分数（`2/5`）、倒计时、经验值（`+20 EXP`）、时间与数量必须开启 `font-variant-numeric: tabular-nums`（或 `.tabular-nums`）。
- **题干层级**：移动端题干 `18–19px` / 字重 `600` / 行高 `1.56–1.58`；桌面端 `19px` / 行高 `1.62`，保证一眼聚焦题目本身。

### 4.2 严格 4 档圆角

- `--radius-sm: 10px`：选项序号标、引导徽章、小型内嵌标签。
- `--radius-control: 16px`：题图与视频封面、常规输入控件、选择题选项卡、线索列表行、通知反馈条、奖品画框。
- `--radius-panel: 24px`：主内容卡片（题卡、登录卡、场次卡、护照卡）、弹窗、抽屉、移动端答题顶栏胶囊。
- `--radius-round: 999px`：主 CTA 按钮、胶囊输入框、圆形提交按钮、分段控制器、悬浮底栏、桌面悬浮顶栏、浮动线索胶囊。

### 5.1 选定的 6 项动效（严格保留 MIT 署名）

本系统所有新增微动效与演出均来自 Motion Prompt，移植代码需保留对应 MIT 署名注释（注意在 `src/styles/` 的 CSS 注释中**不要写 `#002` 等带井号编号**，避免命中字面量色正则，改写为 `Motion Prompt 002`）：

| 编号 | 名称              | 落位场景                                                                                                                                       | 关键参数                                                                                                              |
| ---- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 002  | Stagger           | 场次卡片、收藏网格、来信列表、线索列表错峰入场                                                                                                 | `500ms cubic-bezier(0.34, 1.38, 0.64, 1)`，每项递延 `120ms`（上限封顶，不随长列表无限累积）                           |
| 003  | Burst             | 答对星芒爆发 `StarBurstOverlay`（四芒星蓄力回弹 + 倾斜 `-14deg` 双星环 + 10 射线 + 6 星点）、**升级礼赞 `RankUpDialog`（星穹加冕）**与完成仪式 | 核 `820ms`、环 `620ms`、射线 `620ms`；升级礼赞叠冰蓝+荣耀金双冲击波、12 交错射线、10 放射星尘、三层 3D 星环与八芒星冕 |
| 007  | Count-up          | 护照 EXP 与答对 `+XX EXP` 递增落位轻弹、升级礼赞 `Lv.x` 星核徽章落位                                                                           | `useCountUp` 四次缓出公式 `1 - (1 - p)^4` + 落位 `scale(1 -> 1.07 -> 0.99 -> 1)`                                      |
| 022  | Light sweep       | 当前进行中主焦点场次卡、待领/稀有奖品卡、升级礼赞卡表面荣耀金斜向扫光                                                                          | `24deg` / `-18deg` 斜光带扫过，卡片本体静止                                                                           |
| 051  | Bottom sheet      | 移动端详情 Sheet 与抽屉                                                                                                                        | 从底平滑升起 + 顶部居中抓手条（外层由 `motion.css` 统一管理）                                                         |
| 060  | Segmented control | 启程（待赴/回响）、收藏（待领/已领）等分段切换                                                                                                 | 胶囊轨道内滑块 `250ms` 平滑过渡                                                                                       |

### 5.2 动效硬边界

- 仅对 `transform`、`opacity` 做过渡或关键帧动画；禁止动画 `width`、`height`、`top`、`left`（拖拽控件贴边除外）。
- **外层弹层归属**：以下 11 个弹层容器的外层进出场 `animation` 由 [src/styles/components/motion.css](../src/styles/components/motion.css) 独占，**禁止在其他任何 CSS 中覆盖**：
  `ui-sheet`、`clue-dialog`、`multi-clue-dialog`、`notification-dialog`、`media-viewer`、`rank-up-dialog`、`completion-dialog`、`version-dialog`、`record-confirm`、`avatar-crop-dialog`、`game-retry-dialog`。
- **减少动画**：CSS 中必须配置 `@media (prefers-reduced-motion: reduce)` 折叠装饰动效；JS 中访问 `window.matchMedia` 必须先判断 `typeof window.matchMedia === "function"`（兼容 jsdom 单元测试环境）。

## 7. 工程硬门禁与必守踩坑清单

以下约束均由自动化脚本或 E2E 强校验，修改任意 UI/样式代码时必须逐项自查：

1. **样式架构门禁（`pnpm check:styles` → [verify-style-architecture.mjs](../scripts/verify-style-architecture.mjs)）**：

2. **动效架构门禁（`pnpm check:motion` → [verify-motion-architecture.mjs](../scripts/verify-motion-architecture.mjs)）**：
   - 严禁在 `motion.css` 之外给 11 个弹层容器声明非 `none` 的 `animation`。
3. **布局与组件高频避坑**：
   - **底部独立输入栏避让**：移动端答题页固定底部 `.quest-input-dock` 占底部约 `70px + safe-area-bottom`，`.quest-layout:has(> .quest-input-dock)` 必须保留 `padding-bottom: calc(96px + var(--safe-area-bottom))`；浮动通知铃铛（`{ x: 0, y: 0.84 }`）、`BgmControls`（`{ x: 1, y: 0.84 }`）和 `MultiClueLauncher`（`{ x: 1, y: 0.74 }`）默认悬停在输入栏上方安全区，避免遮挡输入与提交按钮。

   - **透明题图帧**：`question-images.css` 中 `.question-image img`、`.question-gallery img`、`.quest-prompt img` 必须保持 `background: transparent`、`object-fit: contain`，禁止加实色背景遮盖透明 PNG，也禁止 hover 时裁切图片边缘。
