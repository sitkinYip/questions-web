## 回归基准

`GamePlayView.test.tsx` 将原控制器与服务端控制器在相同题面和状态下的题卡 DOM 作直接比较。8 份快照是在临时恢复 Git `8813820` 原文件后实际执行测试生成，再恢复抽取后的文件验证，不是将新版输出自行批准为基准。

覆盖初始、空白、空格、未选选项、答错、提交完成、回顾、无标题、冷却、锁定等。业务成绩仍来自服务端，没有将旧本地判题逻辑接回正式路由。另测自动跳题/媒体/最终关顺序，以及 HTTP 本地域名下的随机请求编号。

浏览器测试继续覆盖桌面 Chromium、移动 Chromium、移动 WebKit。通知测试须等待原本 5 秒首轮查询及响应；多步导航须等待原定位动画完成后再输入，未为测试修改原动画或滚动。

## 可选的本地复配工具

仅在重新创建隔离后端验收环境时使用，不是前端开发依赖。

后台 `backend/scripts/prepare-local-review.mjs` 接收私密 demo-state 和转换 JSON 路径，限定 localhost 后端，导入/发布内容、为测试玩家下发场次，并输出私密 ID 对照报告。相同文件重跑使用原幂等键；更新文件只撤回工具上次创建且尚未开始的旧版本。开始或已完成的记录不会被重置。

自定义 HTTP 本地域名不提供 `crypto.randomUUID`，请求 ID 使用 `getRandomValues` 的密码学随机数兼容实现，正式部署仍要求 HTTPS。依据：[randomUUID](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID)、[getRandomValues](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues)。
